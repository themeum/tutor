# Tutor Context

## Glossary

- **Theme shell**: The optional active WordPress theme header and footer rendered around a Tutor page.
- **Learning Area shell**: Tutor's course header, sidebar, and content layout. When a theme shell is enabled, it is bounded by that shell rather than fixed to the viewport.
- **Learning Area footer**: The course-level navigation and completion controls at the end of Learning Area content. Within a theme shell, it is sticky only inside the Learning Area so it releases before the theme footer.
